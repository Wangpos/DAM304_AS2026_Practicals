3. Background
3.1 The Intuition Behind Attention
When you read the sentence "The bank by the river was muddy", your brain does not give equal
attention to every word when interpreting "bank". It attends more strongly to "river" and
College of Science and Technology, RUB
DAM304 Generative Artificial Intelligence Practical 3
"muddy" because those words help disambiguate the meaning. The attention mechanism gives a
transformer the same ability.
For each token in the sequence, the attention mechanism asks: how much should I attend to
every other token when computing my updated representation? The answer is a set of attention
weights one per other token that sum to 1.0 and are used to compute a weighted average of
value vectors.
3.2 Scaled Dot-Product Attention
Formally, the attention function takes three matrices as inputs: Query (Q), Key (K), and Value
(V). These are computed by multiplying the input X by three learned weight matrices W_Q,
W_K, and W_V respectively. The output is computed as:
Attention(Q, K, V) = softmax( Q * K^T / sqrt(d_k) ) * V
Each matrix has the following dimensions:
Matrix Shape Meaning
Q (n, d_k) Query — what this token is looking
for
K (n, d_k) Key — what this token has to offer
V (n, d_v) Value — the actual content to be
aggregated
Why divide by sqrt(d_k)? When d_k is large, the dot products grow large in magnitude, which
pushes the softmax into regions where gradients are very small (the "saturation" zone). Dividing
by sqrt(d_k) keeps the variance of the dot products approximately equal to 1, regardless of
embedding size. This stabilises training significantly.
3.3 Causal Masking
During pre-training of a decoder-only model (like GPT or LLaMA), we use causal language
modelling ,the model must predict the next token using only the tokens that came before it. To
enforce this, we apply a causal mask: before the softmax, we set the attention scores for all future
positions to negative infinity. After softmax, these become exactly 0.0, meaning the current
token attends to no future token.

DAM304 Generative Artificial Intelligence Practical 3
For a sequence of length 4, the causal mask looks like this:
# 1 = allowed to attend, 0 = masked (set to -inf before softmax)
mask = [[1, 0, 0, 0],
[1, 1, 0, 0],
[1, 1, 1, 0],
[1, 1, 1, 1]]
3.4 Multi-Head Attention
Instead of running one attention function with full d_model dimensions, multi-head attention
splits the embedding into h smaller chunks ("heads") and runs attention independently on each.
The results are concatenated and projected back to d_model.
The intuition is that different heads can learn to attend to different types of relationships
simultaneously. For example, one head may learn syntactic subject-verb agreement while another
learns semantic similarity. Using h heads with d_k = d_model / h maintains the same total
compute cost as single-head attention.
MultiHead(Q,K,V) = Concat(head_1, ..., head_h) * W_O
where head_i = Attention( Q*W_Qi, K*W_Ki, V*W_Vi )

Guidance and Common Mistakes
•
The reshape in split_heads is the trickiest part. After .transpose(1, 2), the tensor is (B, h,
n, d_k). Make sure you call .contiguous() before .view() when merging heads back —
without it you may get a RuntimeError.
•
The causal mask shape must broadcast correctly. Using shape (1, 1, n, n) allows it to
broadcast across both the batch and head dimensions.
•
When you compute weights @ V , both are (B, h, n, d_k) shape — the matmul treats the
last two dims as the matrix dimensions, which is correct.
•
Count your parameters: for d_model=512, h=8, you have four matrices of size 512×512 =
4 × 262,144 = 1,048,576 parameters. If your count is different, you have a shape bug.

Guidance and Common Mistakes
•
Pre-LN applies LayerNorm to the input x before the sublayer, not to the output. This is
the variant used in LLaMA, GPT-2, and most modern transformers because it is more
stable to train.
•
The residual connection adds the original x to the sublayer output. This must happen after
dropout: x = x + self.drop(attn_out). Do not apply dropout to x before the residual.
•
To visualise attention for a specific head, index the weights tensor as weights[batch_idx,
head_idx]. For example, weights[0, 0] gives the 9×9 attention matrix for the first head of
the first example.
•
In the causal heatmap, the upper triangle (above the diagonal) should be completely dark
(zero weight). If it is not, your masking is not working correctly — go back and debug
Task 3.
•
The attention weights are probabilities (row sums = 1.0), so use vmin=0, vmax=1 for the
colour scale to make the heatmap interpretable.
