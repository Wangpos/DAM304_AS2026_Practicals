3. Background
3.1 From Transformer Block to Language Model
A full autoregressive language model wraps the transformer stack in three stages:
1. Input Embedding: Convert integer token IDs into dense vectors of size d_model, then add
positional encoding to inject sequence-order information.
2. Transformer Stack: Pass the embeddings through N identical transformer blocks (each
containing multi-head attention, layer normalisation, and a feed-forward network).
3. Language Model Head: Apply a final layer normalisation then project each output vector
from d_model to vocab_size using a linear layer. The resulting logits are passed through a
softmax to produce a probability distribution over the vocabulary.
During training, the model is given the input sequence x[0:T] and trained to predict the next
token at every position using cross-entropy loss. This is Causal Language Modelling (CLM).
3.2 Cross-Entropy Loss for Next-Token Prediction
For a vocabulary of size V and a sequence of length T, the model produces a logits matrix of
shape (T, V). The loss at each position t is:
L = -log P(x[t+1] | x[0], x[1], ..., x[t])
PyTorch's nn.CrossEntropyLoss takes raw logits (not softmax outputs) and the target token ID.
The loss is averaged over all positions in the batch.
3.3 Autoregressive Text Generation
At inference time, the model generates text one token at a time. Given a prompt, the model
outputs a logit vector for the next position. We take the argmax (greedy decoding) or sample
from the distribution to select the next token, then append it to the sequence and repeat.

Guidance and Common Mistakes
•
Positional encoding must be registered as a buffer (not a parameter) so it moves to the
correct device with .to(device) but is not updated by the optimiser.
•
In generate, slice the input to the last max_seq_len tokens before each forward pass to
avoid exceeding the model's context window: ids = ids[:, -max_seq_len:].
•
Use temperature scaling to control randomness: divide logits by temperature before
softmax. temperature=1.0 is unchanged; temperature<1.0 makes output more
deterministic.
